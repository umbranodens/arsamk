# Self-hosted fonts

The website loads these files through local `@font-face` rules in `index.html`.
No font service is contacted at runtime. Typography tokens are `--font-heading`
and `--font-body`; only the supplied weights are used, with synthesis disabled.
Hero heading sizes at tablet and desktop widths account for Cabin Sketch's
wider letterforms, keeping the heading clear of the illustration.
